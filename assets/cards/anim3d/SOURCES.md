# 3D realistic ANIMATED playing cards — one by one

Search done 2026-11-07 (rounds: image-search ×8 queries + web search ×3).
Goal: individual animated cards (one card per file), 3D/realistic, for Selena's
/blackjack and /highlow. NOT generated — all found online. Every file below was
downloaded and its frames viewed by hand.

## Verdict up front

**No full 52-card animated set exists anywhere found.** The same few Ace GIFs
recur for every card query (GIPHY/Tenor return the same popular Ace for "ten
of spades", "queen of diamonds", etc.), and the "3D" decks sold online are
PHYSICAL lenticular/anaglyph decks (Screams at Midnight 3D with glasses,
Steampunk 3D polygons, Mirage optical-illusion backs) — not GIF sets.
The best real finds are individual animated Aces + two "morphing card" clips
(one card slot cycling through ranks). See "Closest practical route" below.

## Closest practical route to "animated one by one"

No vendor sells/downloads a 52-GIF animated deck. The two realistic options:
1. Use the keepers above as-is (the 3D-spin Ace + fan Ace + morphing hearts
   as reveal/deal moments) with the static Bicycle face set (already in
   `../faces/`) for the actual hands.
2. Flip effect from real images (previous coordinator's option b): attach the
   card BACK, then edit the message to the FACE from `../faces/` — a real
   flip animation per card, using real card art, no GIF needed. This is the
   only way to get EVERY card animated one by one with real faces.
